Family Spelling Bee

Eight rounds, worth more as they get harder. Nobody is eliminated — everyone spells one word a round, and the most points at the end wins.

Game in progress

Players

Two to ten. Leave the rest blank. Speller order is reshuffled every round. The small box beside a name is that player’s own lifeline count — leave it empty to use the default.

Game options

All three are on by default. Turn them off for a straight, classic bee.

  • Before each word: a safer one for a point less, or a harder one for two more.
  • Miss a word and choose between three spellings for half the points.
  • First letter, ask the table, or pass. Set a player's own number beside their name.

How it scores

  • Rounds 1–21 point each — everyday words with one nasty trap
  • Rounds 3–42 points each — educated vocabulary
  • Rounds 5–63 points each — the game starts turning here
  • Rounds 7–84 points each — obscure, then genuinely hard
  • Safe wordtwo rounds easier, one point less
  • Risky wordtwo rounds harder, two points more
  • Second chancehalf the points, rounded up
  • Perfect game20 points, or 34 if you gamble on every word. Ties stand
